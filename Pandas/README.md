## Four-Phase Learning Journey

### Phase 1: Pandas Foundations

**What We'll Learn:**
- Core data structures (Series, DataFrame)
- Reading and writing data (CSV, Excel, JSON)
- Data selection and indexing (loc, iloc, at, iat)
- Filtering with boolean indexing and query method
- Memory optimization techniques

**Key Skills:**
Create and manipulate DataFrames  
Load data from multiple formats  
Select and filter data efficiently  
Optimize memory usage  

---

### Phase 2: Data Cleaning

**What We'll Learn:**
- Missing value detection and imputation
- Duplicate identification and removal
- String cleaning and normalization
- Data type conversion and validation
- Production-ready cleaning techniques


**Key Skills:**
Handle all types of missing values  
Detect and remove duplicates  
Clean and normalize text data  
Convert and validate data types  

---

### Phase 3: Mini Project - Data Cleaning

**What We'll Build:**
- Complete end-to-end data cleaning pipeline
- Transform messy data (2.3 KB) to clean data (1.8 KB)
- Resolve 9 different data quality issues
- Production-ready preprocessing workflow

**Key Skills:**
Design systematic cleaning workflows  
Handle multiple quality issues  
Validate and document results  
Deliver production-ready data  

---

### Phase 4: ADVANCED

**What You'll Master:**
- GroupBy operations and aggregations
- Merging and joining multiple datasets
- Pivot tables and cross-tabulation
- Data reshaping (melt, stack, unstack)
- Sorting and ranking techniques
- Time series analysis and forecasting

**Key Skills:**
Perform complex aggregations  
Combine multiple data sources  
Create analytical pivot tables  
Reshape data for analysis  
Analyze time series data
